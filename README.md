# PSG-Recruitment-Analytics
## Project Overview
This project proposes a decision-support tool for Paris Saint-Germain (PSG) that uses player analytics to support recruitment and squad-planning decisions. The tool is designed to evaluate potential recruitment targets across performance, positional fit, and estimated player value.

## Decision-Making Problem
PSG recruits from a broad European player market, creating a large pool of potential candidates. Recruitment personnel must determine which players warrant further scouting and consideration while accounting for squad needs and available transfer resources. The project supports a more structured process for identifying and prioritizing viable recruitment targets.

## Proposed Analytics Approach
The analysis will use player-performance data such as goals, assists, expected goals, expected assists, playing time, and relevant per-90 measures where available. Players will be compared within appropriate positional groups, with estimated player value incorporated to provide additional acquisition context.

## Use by Decision Makers
Recruitment personnel, scouts, and sporting leadership could use the tool during candidate screening and squad-planning discussions. Analytics would provide comparable candidate profiles and prioritized recruitment targets, while scouting observations and leadership judgment would remain part of the final recruitment decision.

## Connection to Chapter 7
The project currently represents the creative phase of the innovation framework because the analytical concept, decision problem, intended users, and proposed approach have been defined, but the decision-support tool has not yet been developed or tested. This establishes the foundation for subsequent prototyping and engagement with decision makers.

## Prototype Enhancement
The prototype will add a recruitment value indicator that combines player performance, positional fit, and estimated player value. This enhancement would allow decision makers to compare potential recruitment targets more efficiently and identify players who provide strong performance while also addressing PSG's squad needs and available transfer resources.
